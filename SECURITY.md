# Security policy

## Supported versions

Security fixes target the latest tagged release. Please check whether the issue still occurs on that release before reporting it.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting on this repository's **Security** tab. Include the affected version, impact, and reproduction steps. Do not open a public issue or pull request with exploit details, API keys, webhook secrets, or customer data.

The maintainers will review the report and coordinate a fix and disclosure through GitHub Security Advisories.
